# Access Standard v4 - approved 2025-11-01

Rivet & Root Bicycle Cooperative uses the BenchBoard service on a shared tablet at the front counter. The standard requires multifactor authentication for staff accounts. Exception EX-041 permits the shared BenchBoard account only through 2026-09-30 while the tablet workflow is replaced. Only the Operations Director may approve an extension in writing.

Before the exception expires, the shared account must be retired or replaced with individually assigned accounts protected by MFA. This standard records the requirement and approved end date; it does not show that configuration changed or that the account was closed.
